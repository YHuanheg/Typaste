# The history of Typaste

## English

- 2019-08-07 ver.0.5.1 First release.
- 2019-08-14 ver.0.5.2 Added "Open ReadMe".
- 2023-11-14 ver.0.5.3 Added sounds. Added "Delay to start".
- 2024-04-25 ver.0.5.4 Added "Play" button. Added "Control IME On/Off".
- 2024-05-08 ver.1.0.0 Made "Control IME On/Off" default. Added spin controls.
- 2024-05-16 ver.1.0.1 Added manifest and version info. Supported Windows 2000.
- 2024-05-20 ver.1.0.2 The details were properly localized. Added "(None)" to the sound.
- 2026-01-08 ver.1.0.3 Fixed the main icon on the dialog not being displayed.
- 2026-01-08 ver.1.0.4 Fixed "Open ReadMe".
- 2026-01-15 ver.1.0.5 Added a randomization setting for typing intervals.
- 2026-10-31 ver.1.1.0 Added the language selection (Simplified/Traditional Chinese). Improved for x64. Maintainer: YHuanheg.
- 2026-10-31 ver.1.2.0 Added Unicode input for CJK/emoji, a worker thread, the About box, reset-to-defaults, DPI awareness and a redesigned UI. Maintained by YHuanheg.
- 2026-11-01 ver.1.3.0 Added the tray icon, the program whitelist, Per-Monitor V2 DPI awareness, CI builds and optional code signing.
- 2026-11-07 ver.1.4.0 Split the sources into modules, added the LANG_NEUTRAL fallback, Typaste.ini, the speed slider and the clipboard preview with selection-only typing. C++17.

## Japanese (日本語)

- 2019-08-07 ver.0.5.1 初公開。
- 2019-08-14 ver.0.5.2「ReadMe を開く」を追加。
- 2023-11-14 ver.0.5.3 音声を追加。開始遅延を追加。
- 2024-04-25 ver.0.5.4 「音声の再生」を追加。「IMEのオン／オフを制御」を追加。
- 2024-05-08 ver.1.0.0 「IMEのオン／オフを制御」をデフォルトに。スピンコントロールを追加。
- 2024-05-16 ver.1.0.1 マニフェストとバージョン情報を追加。Windows 2000のサポート。
- 2024-05-20 ver.1.0.2 細かいところをちゃんとローカライズした。音声に「(なし)」を追加。
- 2026-01-08 ver.1.0.3 ダイアログ上のメインアイコンが表示されていなかったのを修正。
- 2026-01-08 ver.1.0.4 「ReadMeを開く」を修正。
- 2026-01-15 ver.1.0.5 タイピング間隔のランダム化設定を追加。
- 2026-10-31 ver.1.1.0 言語の選択 (簡体字/繁体字中国語) を追加。x64 向けに改善。メンテナ: YHuanheg。
- 2026-10-31 ver.1.2.0 中国語・絵文字の Unicode 入力、ワーカースレッド、バージョン情報、設定の初期化、高 DPI 対応を追加。ダイアログを一新。メンテナー: YHuanheg
- 2026-11-01 ver.1.3.0 トレイアイコン、プログラムの許可リスト、Per-Monitor V2 DPI、CI ビルド、コード署名 (任意) を追加。
- 2026-11-07 ver.1.4.0 ソースをモジュールに分割し、LANG_NEUTRAL フォールバック、Typaste.ini、速度スライダー、クリップボードのプレビューと選択部分のみの入力を追加。C++17。

## Chinese (简体中文)

- 2026-10-31 ver.1.2.0 支持中文/emoji 的 Unicode 输入、后台输入线程、关于对话框、恢复默认设置、高 DPI 与新界面。维护者：YHuanheg。
- 2026-11-01 ver.1.3.0 新增托盘图标、程序白名单、Per-Monitor V2 DPI、CI 构建与可选代码签名。
- 2026-11-07 ver.1.4.0 源码拆分为多个模块，新增 LANG_NEUTRAL 回退、Typaste.ini 配置文件、速度滑条、剪贴板预览与只输入选中部分。使用 C++17。
- 2026-10-31 ver.1.1.0 新增界面语言选择（简体/繁体中文）。针对 x64 改进。
