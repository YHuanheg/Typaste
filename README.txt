# Typaste

Typing + Paste == Typaste.

Typaste intercepts the pasting process by Ctrl+V while its window is displayed
and emulates text input like typing. This allows you to break through the paste
prohibition.

Press the Esc key to stop typing.

License: MIT

## Features

- CJK/emoji input via SendInput + KEYEVENTF_UNICODE (no keyboard layout needed)
- Typing runs on a worker thread (the window stays responsive)
- Adjustable typing/start delay, random interval, hot-key, IME control, sound
- Typing speed slider in the settings dialog
- English / Japanese / Simplified Chinese / Traditional Chinese UI
- High-DPI aware (Per-Monitor V2), About box, reset to defaults
- Clipboard preview: the current clipboard text is shown in the window; select a
  part of it and the hot-key types only the selection
- Tray icon with a context menu; the window minimizes to the notification area
- Program whitelist: intercept Ctrl+V only in the programs you choose
- Portable Typaste.ini next to the exe (falls back to the registry)

## Supported Platforms

Windows Vista/7/8.1/10/11 x64 (primary). A Win32 (x86) build is also available.

## Languages

Choose the language in [Settings...] - [Interface language].
"Follow the system" follows the UI language of Windows. The change takes effect
immediately. When the system language is not one of the four, the UI falls back
to English (LANG_NEUTRAL resources).

## Configuration

Settings live in Typaste.ini next to Typaste.exe (language, delays, hot-key,
sound, whitelist). Delete the file to use the registry again.

## Building

    cmake -S . -B build-x64 -A x64 -DCMAKE_BUILD_TYPE=Release
    cmake --build build-x64 --config Release

Without CMake, run build_x64.bat. The localized resources are generated by
python tools/gen_lang.py.
