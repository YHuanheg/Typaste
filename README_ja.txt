# Typaste

Typing + Paste == Typaste.

Typaste (タイペースト) は、Ctrl+V による貼り付け処理を割り込み、
まるで打ち込むようにテキスト入力をエミュレートするプログラムです。
これにより、貼り付け禁止を突破できます。

Esc キーで入力を停止できます。

ライセンス: MIT (フリーソフト)

## 特徴

- 中国語・日本語・絵文字などの文字も Unicode 入力 (SendInput + KEYEVENTF_UNICODE) で送信
- 入力処理はワーカースレッドで実行され、ウィンドウは固まりません
- 一時停止／再開: 任意の文字の切れ目で止めて、そこから続行できます
- 停止後の続き: Esc で止めたあと「続きから」で残りだけを入力します
- タイプ遅延／開始遅延／ランダム間隔／ホットキー／IME 制御／音声に対応
- 入力法の制御: 入力中は IME を英数モードに切り替え（または閉じ）、終了後に元の状態へ戻します
- 文字ごとに IME を切り替える「適応入力」に対応（ASCII → 英数、CJK → ネイティブ）
- 「そのまま出力」: IME を退避させて全文字を Unicode 入力で送ります
- 設定に速度スライダーを追加
- 表示言語: English / 日本語 / 简体中文 / 繁體中文
- 高 DPI 対応 (Per-Monitor V2)、バージョン情報、設定の初期化
- クリップボードのプレビュー: ウィンドウに現在のクリップボードを表示し、
  一部を選択しておくとホットキーは選択部分だけを入力します
- トレイアイコンと右クリックメニュー。最小化すると通知領域に収まります
- プログラムの許可リスト: 選んだプログラムでのみ Ctrl+V を横取りします
- ポータブル設定 Typaste.ini (exe と同じフォルダ、無い場合はレジストリ)

## 対応環境

Windows Vista/7/8.1/10/11 x64 (メイン)。Win32 (x86) ビルドも可能です。

## 表示言語

[設定変更...] の [言語] で選択できます。「システムに合わせる」では Windows の
表示言語に従います。切り替えはすぐに反映されます。システムの言語が4つの
いずれでもない場合は英語 (LANG_NEUTRAL) にフォールバックします。

## 設定ファイル

設定は Typaste.exe と同じフォルダの Typaste.ini に保存されます
(言語、遅延、ホットキー、音声、許可リスト)。削除するとレジストリに戻ります。

## ビルド

    cmake -S . -B build-x64 -A x64 -DCMAKE_BUILD_TYPE=Release
    cmake --build build-x64 --config Release

CMake を使わない場合は build_x64.bat を実行してください。
ローカライズ資源は python tools/gen_lang.py で生成します。
